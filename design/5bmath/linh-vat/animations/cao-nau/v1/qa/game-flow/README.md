# Kiểm tra luồng game Cáo Nâu

Các báo cáo qa-game-report*.json và game-*.png lấy từ phép thử giao diện game thực bằng fixture thử riêng. Request backend được giả lập/đáp bởi công cụ QA, không phải tài khoản hay trận đấu DB thật; kết quả HTTP/Docker được xác minh riêng ở phiên gốc. ultimate-overlay-390.png lưu mẫu trước sửa cắt tai để truy vết; ultimate-bounds-390.png là khung sau sửa. ultimate-bounds-report.json xác minh hình nhân vật đã xoay còn đầy đủ trong352px qua20mốc/hướng và một khung xem, không có lỗi JavaScript. Không đo FPS trên điện thoại thật.
